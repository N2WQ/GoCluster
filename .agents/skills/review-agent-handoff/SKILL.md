# Review an agent handoff

Start with the owner's intended outcome. Read the named, accessible chat,
attachment, or artifact directly. For a follow-up, use the previously identified
source and find the latest relevant exchange. Resolve the target branch, revision,
or data set when it could change the answer. If a source is inaccessible, use
the available evidence and request only the missing part that affects the decision.

Reconstruct the other agent's strongest argument fairly. What did it observe,
what mechanism does it propose, and what outcome does it predict? Preserve its
qualifications. Attribute suggestions to their author and carry forward the
owner's actual decisions. Apply the repository's existing approval boundary.

Verify each consequential premise with evidence suited to the claim. Trace code
through the relevant caller, configuration, and observable behavior. For empirical
claims, check what was measured, against which baseline, and whether the comparison
supports the claimed outcome. Use the applicable specialist method, including the
scientific review and independence rules when triggered.

Before recommending action, look for the strongest credible counterexample or
alternative explanation. Test your own objection with the same care. On later
rounds, identify what changed and revisit earlier findings whose premises are
affected. Credit corrections and close points the evidence settles.

Lead with the next justified action and its practical consequence in plain English.
Continue review when a remaining uncertainty could change that action or expose a
material risk in taking it. Perform the smallest decisive check within the authorized
review when feasible. Otherwise explain what evidence is missing and how the result
would change the decision. If an owner preference determines the outcome, explain
the options, your recommendation, and what happens if things stay as they are.
When the evidence settles the next step, close the review. Include a concise,
self-contained reply for the other agent when it would advance the work. In a
draft reply, present your recommendations as proposals and attribute only
confirmed preferences or decisions to the owner.
